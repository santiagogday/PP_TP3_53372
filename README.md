# Trabajo Práctico de Prolog

Trabajo práctico de Programación Lógica para la materia Paradigmas de Programación.

## Ejercicios realizados

- Factorial.
- Cantidad de elementos de una lista.
- Suma de elementos.
- Último elemento de una lista.
- Filtrado de números pares.
- Eliminación de elementos.
- Inserción de elementos por posición.
- Inserción ordenada y ordenamiento de listas.
- Consultas sobre hechos.
- Relaciones en grafos y árboles genealógicos.

## Herramienta utilizada

Se utilizó JIProlog para cargar y probar los predicados.
